Server integration

The exported asynchronous initializer in index.js receives a server object. It registers authentication routes beneath AUTH_API_PREFIX, attaches middleware to /proxy/*, and creates the serverless API used by its plugins. Gatekeeper is a server extension; this package has no standalone start command.

Login and sessions

UserLogin coordinates email codes, passkeys, and TOTP with persisted account records. Successful authentication returns session information to HTTP handlers, which set authentication cookies. The proxy middleware checks whether a session belongs to a blocked user and validates sessions before allowing protected plugin calls.

Coding style defines source layout and the verification commands. Wiki contains the canonical project terms.
