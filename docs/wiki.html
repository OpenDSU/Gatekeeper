Wiki

These terms describe the project's own components and contracts.

UserLogin

UserLogin is the account plugin used by the HTTP handlers and proxy authentication middleware. It coordinates login strategies, persistence, account creation, session validation, and logout. Email code, passkey, and TOTP strategies implement distinct credential checks; session and registration caches are process-local and do not establish a shared multi-process cache.

Serverless API

The host server creates and registers a plugin API under SERVERLESS_ID. Gatekeeper handlers use an OpenDSU serverless client to call plugins with the current user and session context. Gatekeeper relies on that host contract rather than opening its own standalone listener.

Session

A successful login creates a session identifier associated with a persisted account. Handlers expose authentication cookies, and protected proxy calls use the session to retrieve identity. UserLogin checks its local cache and persistence and removes the session during logout; browser headers alone are not a substitute for session validation.
